## Data notice

All messages, phone numbers, names, email addresses and links in this folder were invented for this project. They were written to follow the scam patterns described in official advisories, and no real victims' messages were used.

Organisation names (banks, couriers, online marketplaces, employers and government agencies) appear only to recreate those documented patterns. The messages were not sent by, and are not endorsed by, any of these organisations. Any match between an invented phone number, name or link and a real one is coincidental. Do not call, message or visit any number or link in this dataset.

## Advisory excerpts

Each file in `advisories/` quotes a short passage from the page given in its `source_url` field. The excerpts are included for non-commercial educational use, with attribution, and all rights remain with their owners. If you are a rights holder and would like an excerpt removed, please open an issue.
